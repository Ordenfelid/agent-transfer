# Agent Transfer（Agent 上传下载）

为思源 Agent 提供两个内核工具：把网络文件或 base64 内容**下载**存入工作空间附件、把附件**上传**到指定链接。需要思源笔记 ≥ 3.8.5；插件在内核运行、装好即用，无任何设置项。

工具触发思源自带的 Agent 审批流（外发流量、写入附件照常弹窗），审批策略跟随你在思源里的 Agent 设置。开启思源内置 MCP 服务后（设置 → AI → MCP），外部 MCP 客户端也能调用这两个工具。

对 Agent 说「下载这个图片：https://example.com/a.png」即可体验。

## 下载：把网络文件存入附件

Agent 工具 `download_asset`，两种方式二选一：

- **`url`**：给出 http(s) 链接，由内核代理抓取后存入附件；
- **`dataBase64`**：直接给出 base64 内容（如模型生成的图片、从别处复制来的文件），此时 `filename` 必填。

`url` 方式下 `filename` 可选，缺省自动推断并补全扩展名。文件存入工作空间 `assets/`，按思源规范自动命名去重，返回可在文档中直接引用的附件路径。

单文件上限 32 MB；仅支持 http/https 链接，本机/内网地址会被拒绝。失败时 Agent 会收到具体原因，可自行纠正参数后重试。

## 上传：把附件发到外部链接

Agent 工具 `upload_asset`，目标地址不受名单限制，由思源 Agent 审批流统一把关（弹窗内容含写入与外发声明）。

参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `path` | 是 | assets 内的文件；可只写原始文件名，自动匹配思源的时间戳后缀副本 |
| `url` | 是 | 接收文件的 http(s) 链接，支持 `{{vars.名称}}` 变量 |
| `method` | 否 | `POST`（默认）或 `PUT` |
| `headers` | 否 | 附加请求头；凭据用 `{{secrets.名称}}` 引用（见下） |
| `multipart` | 否 | `true` 时按表单方式上传，适配网盘/文件分享类接口 |
| `fileField` / `fields` | 否 | 表单模式下的文件字段名（默认 `file`）与附带文本字段 |

上传成功后，远端响应（如文件分享链接）会回传给 Agent。限制：单文件 32 MB；仅 http/https，本机/内网地址一律拒绝；只能上传 assets 内的文件。

### 凭据（token 等鉴权信息）

在 **思源 设置 → AI → 密钥** 里配置密钥及其允许的主机，Agent 在请求头中以 `{{secrets.名称}}` 引用。明文凭据不会出现在对话、日志或返回结果里，也只会发送给你授权过的主机。
